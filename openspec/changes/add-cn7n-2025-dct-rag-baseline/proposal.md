# Proposal

## Why

2025년식 아반떼 N DCT 사용자가 보유한 매뉴얼에서 자신의 차량에 맞는 근거를 찾고,
페이지를 확인할 수 있는 답변을 얻어야 한다. 원본 PDF는 수집됐지만 파싱·검색·답변의
구현과 평가 기준이 없어, 대표 매뉴얼 한 권으로 전체 흐름과 단계별 품질을 검증한다.

## What Changes

- 사용자에게 확인한 차량 조건 `CN7N / 2025 / DCT`와 기존
  `data/raw/hyundai/passenger/CN7N_2025_ko_KR.pdf`를 최초 지원 대상으로 한다.
- 기존 manifest와 실제 파일의 크기·SHA-256을 검증하여 등록하고 원본을 보존한다.
  의심스러운 출처 URL은 검증 상태를 기록하고, 확인되지 않은 주소를 인용 링크로 만들지 않는다.
- 전체 페이지의 처리 상태를 기록하고, 본문·표·각주·경고·적용 조건 및 PDF/인쇄 페이지를
  추적 가능한 공통 형식으로 추출한다. OCR·그림 해석이 필요한 구간은 명시적으로 남긴다.
- 절과 표의 구조를 고려한 청크, OpenAI `text-embedding-3-small` 임베딩과 로컬 FAISS 색인,
  차량·변속기 조건을 적용한 검색을 도입한다.
  공통과 DCT 근거를 사용하며 수동 전용·적용 미확인 근거를 임의로 적용하지 않는다.
- CLI에서 근거 검색과 한국어 답변을 제공한다. 답변에 실제 검색 근거의 문서·페이지를
  표시하며 근거 부족, 사양 확인 필요, 처리 장애를 구분한다.
- 대표 질문 16개와 합성 회귀 사례로 파싱·검색·답변을 별도 평가한다.
  실제 모델 평가와 외부 연결 없는 자동 테스트를 분리한다.
- 사용자가 요청한 빠른 구현을 위해 OpenAI API로 생성하고 Python SDK를 직접 연결한다.
  생성 모델은 사용자 선택 `gpt-5-mini`를 기본으로 설정하고 실제 API로 계정 접근을 검증한다.
- 일반·표·사양·근거 부족 각 1개, 총 4개 질문으로 파싱부터 인용 답변까지 먼저 연결한 뒤
  전체 페이지 처리와 16개 평가로 확장한다. 초기 데모 통과를 최종 검증 완료로 간주하지 않는다.

이번 범위에서 제외하는 것은 전체 134개 PDF 일괄 처리, 추가 수집기, 온라인 전용 매뉴얼,
웹 UI·배포, 에이전트의 자율 재검색, 자동 OCR·그림 해석이다. 원본 PDF는 배포하지 않는다.
제외된 문서 처리 때문에 누락된 근거를 전체 매뉴얼에 없는 내용으로 단정하지 않는다.

## Capabilities

### New Capabilities

- `manual-ingestion`: 원본 검증·등록, 페이지와 구조 보존, 처리 누락 및 재생성 이력 관리.
- `vehicle-scoped-retrieval`: 적용 범위가 연결된 청크와 색인을 생성하고 차량 조건으로 근거 검색.
- `grounded-manual-answers`: 검색 근거 기반 답변, 인용 연결, 부족한 근거와 장애 구분.
- `rag-quality-evaluation`: 재현 가능한 질문 세트와 단계별 평가·완료 기준.

### Modified Capabilities

없음. 현재 프로젝트에 등록된 기존 명세는 없다.

## Impact

- 신규 Python 패키지, CLI, 프로젝트 가상환경·의존성 잠금 파일, 테스트와 평가 사례가 필요하다.
  구체적인 책임 경계와 기술 대안은 design.md에 정의한다.
- 새 로컬 파싱 데이터와 검색 색인을 원본과 분리한다. 재실행·설정 변경 시 기존 정상 결과와
  색인의 호환성을 보장해야 한다.
- OpenAI API 키와 네트워크가 실제 색인·질의에 필요하다. 임베딩에는 처리할 청크와 질문,
  생성에는 질문·차량 조건·선택된 근거가 전송되며 사용량에 따른 비용이 발생한다.
  PDF 파일 자체를 업로드하거나 배포하지 않는다. 자동 테스트는 모의 API로 비용 없이 실행한다.
- FAISS CPU 인덱스와 JSON 메타데이터를 동일 데이터 세대로 관리한다. 로컬 모델 설치와
  별도 DB 서버·SQLite 저장 계층은 초기 구현에서 제외한다.
- 구현 시 루트 README와 AGENTS.md의 실제 모듈·명령 정보를 갱신하고, 원본·생성 데이터·
  캐시·개인 설정의 Git 및 배포 제외 규칙을 확인한다. 현재 계획 단계에서는 이 파일들을 수정하지 않는다.
- 기존 구현·공개 API가 없어 이전 API와의 호환성 변경은 없다.
