# Tasks

현재 문서는 구현과 검증 상태를 추적한다. 모든 체크는 코드·산출물과 검증 결과를 확인한 후에만 변경한다.
임베딩 `text-embedding-3-small`, OpenAI 생성 API, FAISS는 사용자 요청으로 확정됐다.
생성 모델은 사용자 선택 gpt-5-mini를 기본으로 사용한다. 키·계정 접근 권한이 없으면 실제 API 평가는 미완료로 남긴다.
빠른 구현을 위해 5.4에서 대표 질문 4개의 전체 흐름을 먼저 검증하고, 이후 16개 평가와 전체
페이지 처리로 확장한다. 처음부터 로컬 모델 설치·범용 제공자 체계·별도 DB 계층을 만들지 않는다.

## 1. 프로젝트 실행 기반과 공통 계약

- [x] 1.1 Python 3.11 프로젝트 가상환경, 최소 패키지 구조, pyproject.toml과 버전 잠금을 구성한다. pdfplumber·openai·faiss-cpu·numpy·tiktoken 및 테스트 의존성을 고정하고 Windows의 깨끗한 가상환경에서 import와 FAISS 저장/읽기를 확인한다.
- [x] 1.2 VehicleProfile, Document, Page, Block/Table, Chunk, IndexBuild, SearchResult, Answer 계약과 외부 입력 검증을 구현하고 누락 필드·잘못된 enum·페이지 범위·경로 입력의 합성 테스트를 통과시킨다.
- [x] 1.3 TOML/환경변수 설정과 CLI 명령군을 구성하고 CN7N/2025/DCT, text-embedding-3-small/1536, OPENAI_API_KEY, 생성 모델 설정을 연결한다. ingest는 키 없이, search는 생성 모델 없이 동작하며 필요한 키·설정 누락은 비정상 종료하는지 테스트한다.
- [x] 1.4 원본·생성물·색인·로컬 설정·평가 상세·캐시를 Git 및 패키지 배포에서 제외하고 빌드 산출물에 PDF가 없음을 확인한다. README와 AGENTS.md에 실제 경로·설치·테스트 명령을 기록한다.
